receiver 的身份判断与 seed 选择是两个步骤：先用 place_context 确定任务完成时与 target
直接接触的是哪个对象或区域，再回到 receiver 允许的 seed 候选中选择同一对象最清晰的一帧。
seed 中二者不需要已经接触；只要该对象在任一允许候选中清晰可见，即使它在 place_context
中被 target 或夹爪部分遮挡，也不得因此返回 no_clear_seed。

请利用任务文本和多帧动作关系判断所有要求的角色，不要只凭一张静态图猜测。

对每个角色：
1. 只能从该角色允许的 seed 候选中选择一个完整、清晰、遮挡最少的 seed frame。必须逐一
   比较所有允许候选，不得因为 frame id 最小或排在输入最前就默认选择。若多个候选接近，
   优先选择跨相邻候选外观稳定、曝光正常且夹爪尚未接触主体的帧，并在 reason 中写明比较依据；
2. 输出有序 query candidate bank，而不是一条长 referring expression；
3. 每条非空 query 必须是 1–4 个小写英文词组成的、指向完整物体的单数名词短语；
4. 三维物体 query 必须保留完整类别名。颜色词或形状词不能充当 head noun，例如 target
   bottle 不能只写 white。对于 pad、mat 等薄平面目标区域，除了带类别名的 query，还允许在
   shape_category_query 中给出一个稳定可见的“颜色 + 形状”别名（如 blue square）；这是
   SAM3 对平面区域的专用补充候选，不能用于普通三维物体。每条 query 总词数不得超过 4；
5. 只使用多帧中稳定可见的属性，不猜测无法确认的属性；
6. 禁止冠词/所有格、品牌或 OCR 文字、数字、动作、位置、空间关系、比较级以及包含
   with 的长属性串；禁止只描述 cap、logo、label、handle 等子部件；
7. category_query 必须是简单、常见、可直接检测的无修饰完整类别，通常使用物体 head noun；
   不得把任务文本中的用途、商品亚型或尺寸词拼成类别，例如 medicine bottle、pill bottle、
   compact bottle 的 category_query 都应是 bottle。有颜色或形状/材质证据时填写
   color_category_query、shape_category_query。general_fallback_query 必须更一般但仍是有
   视觉意义的完整物体类别（例如 container、mat），且永远排在最后；如果没有合理的上位
   类别就填写 null，禁止使用 object、thing、item、stuff 等空泛词；
8. recommended_order 排的是预计 SAM3 分割鲁棒性，不是描述详细程度。对于 target 这类常见
   三维可操作物体：如果提交帧中没有第二个同类别实例，recommended_order 第一项必须是
   category_query；只有确实看见多个同类别实例、需要属性消歧时，颜色/形状候选才可排第一。
   属性明显或任务文本提到属性，本身都不足以改变这条排序规则。若存在多个同类别实例，
   color_category_query 必须保留图像和任务共同确认的关键消歧颜色；双色设计是必要消歧信息时
   应保留两个颜色，例如 teal white bottle，不能退化成可能指向其他实例的 teal bottle；
9. 对 pad、mat 等薄平面接触区域，如果颜色和形状都稳定清晰，应在
   color_category_query 中保留“颜色 + 形状 + 类别”的紧凑组合并优先排序，并在
   shape_category_query 中提供第 4 条所述的“颜色 + 形状”SAM3 别名；此规则按当前图像
   动态判断，不能照抄示例文字；
10. 所有非空候选必须互不相同。若某个可选字段只能生成与已有候选相同的短语，或没有独立的

    所有非空候选字段且不重复。输出前按小写并合并空格后再次检查候选是否重复；
