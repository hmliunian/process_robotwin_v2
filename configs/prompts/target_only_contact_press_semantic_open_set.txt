角色定义：
- target：夹爪闭合后即将直接接触并驱动的最小完整、可分割功能部件，例如按钮、开关、把手
  或盖板；没有独立可见部件时才是完整可见对象。

本模式只识别 target，不推断其他对象角色。seed 帧可以发生在实际接触之前；target 不需要被
抓取、持有、带走或与夹爪同步运动。必须结合任务文本、active_arm 的接近轨迹以及 close_end
后的动作上下文判断夹爪准备触碰哪里，不能只凭类别名或一张静态图猜测。用途标签中的
post_grasp_context 在本 profile 只表示闭爪后的动作上下文，不代表 target 已被抓取或持有。

对 target：
1. 逐一比较所有允许的 seed 候选，选择目标或 action site 完整、清晰、遮挡最少且曝光稳定的
   一帧；夹爪尚未接触 target 不能成为拒绝 seed 的理由；
2. 即使任务文本只写设备名，也要用接近轨迹识别实际将被驱动的最小完整可分割功能部件，不能
   强行扩展到整个设备；禁止输出无视觉边界的抽象接触点或任意小块表面。没有独立可见部件时，
   target 才是完整可见对象；
3. 输出有序 query candidate bank，而不是带位置、手臂或动作的 referring expression；
4. 每条非空 query 必须是 1–4 个小写英文词组成的单数名词短语，并指向完整 target；允许用
   button、switch、handle、lid 等任务明确的部件类别作为 head noun；
5. category_query 必须是简单、常见、可直接检测的类别名。颜色、形状或材质不能单独充当
   head noun；任务中的用途、商品亚型或尺寸词不得机械拼入类别名；
6. color_category_query 和 shape_category_query 只能使用多帧中稳定可见的真实属性；
7. general_fallback_query 可忠实描述 target 的真实外观，例如 red button、silver handle、
   white bar 或 brown panel。允许“视觉属性 + object”，但禁止裸 object、thing、item、stuff；
8. 禁止冠词、所有格、品牌/OCR、数字、动作、位置、空间关系、比较级以及包含 with 的长属性串；
9. recommended_order 按预计 SAM3 分割鲁棒性排序；属性仅用于同类实例消歧，
   general_fallback_query 非空时必须排在最后；
10. 所有非空候选必须互不相同；缺少独立视觉依据时填写 null，不能复制已有短语；
11. 如果没有任何合法候选清楚显示夹爪准备触碰的完整 target/action site，返回
    no_clear_seed，不得选择夹爪、背景或无关实例。
