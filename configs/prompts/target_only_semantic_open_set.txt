角色定义：
- target：随后被 active_arm 对应夹爪抓取、移动并持续持有的完整物体。

本模式只识别 target，不推断也不输出其他对象角色。必须利用 close 前后的接触关系
和 close_end 后与夹爪同步运动的证据确认实例，不能只凭任务类别名或一张静态图猜测。
close_end 之后的图像只用于确认对象身份，不会延长 target 的 mask 时间窗口。

对 target：
1. 必须逐一比较所有允许的 seed 候选，选择完整、清晰、遮挡最少且曝光稳定的一帧；不得因为
   frame id 最小或排在输入最前就默认选择。夹爪尚未接触主体且相邻帧外观稳定时优先；
2. 输出有序 query candidate bank，而不是一条带位置或动作的 referring expression；
3. 每条非空 query 必须是 1–4 个小写英文词组成的单数名词短语，并指向完整物体；
4. category_query 必须是简单、常见、可直接检测的完整类别名。颜色、形状或材质不能单独充当
   category_query 的 head noun；任务中的用途、商品亚型或尺寸词不得机械拼入类别名；
5. color_category_query 和 shape_category_query 只能使用多帧中稳定可见的真实属性，不能使用
   cap、logo、label、handle 等局部代替完整物体；
6. general_fallback_query 是最后一道开放集视觉回退。当任务类别与模拟资产外观不一致时，可以
   忠实描述当前完整物体的真实外观，例如 silver object、white bar、small red object 或
   brown platform。允许“视觉属性 + object”，但禁止裸 object、thing、item、stuff；
7. 禁止冠词、所有格、品牌/OCR、数字、动作、位置、空间关系、比较级以及包含 with 的长属性串；
8. target 身份以夹爪实际接触、抓取和同步运动证据为准。任务称 stapler 但完整资产看起来像
   white bar，或透明倾斜物体不像现实类别原型时，不得仅因外观不典型而改选其他实例；
9. recommended_order 按预计 SAM3 分割鲁棒性排序。常见且唯一的三维物体通常先放
   category_query；属性用于同类实例消歧。general_fallback_query 非空时必须排在最后；
10. 所有非空候选必须互不相同；无法生成有独立视觉依据的候选时填写 null，不能复制已有短语；
11. 如果没有任何合法候选清楚显示完整 target，返回 no_clear_seed，不得选择局部或其他实例。
