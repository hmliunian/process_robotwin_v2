The target is the smallest complete visible functional part that the gripper will drive. For a
room-door task, the target is the complete graspable door handle or lever, including its full
visible grip and the handle's own visible mounting rose/backplate when that structure belongs to
the handle assembly. For an appliance-door task, it is the complete door handle including both
visible ends and their mounting pieces. Follow the task description: never reject a room-door
handle merely because it is not attached to an appliance, and never accept a cart, robot-base,
equipment, cabinet, or appliance handle when the task is to open the room door.

Keep the word ``handle`` as the semantic head in every handle candidate; do not replace it with
``vertical bar``, ``latch``, ``door``, ``panel``, or ``body``. Do not use ``microwave door``,
``room door``, or any phrase naming the whole door/appliance as a handle candidate. If a separate
handle exists but is incomplete or occluded in every seed frame, return ``no_clear_seed`` rather
than a partial handle, one attachment foot, door edge strip, lock cylinder, door panel, or fixed
housing. A ``door panel``/``moving door panel`` phrase is a proxy only when visual evidence shows

non-empty query must name the same door-panel proxy rather than the fixed frame or housing. Never

physical contact is valid.

Seed selection is an explicit visual decision: compare every frame marked
``seed_candidate=yes``. Prefer the frame where the complete target spans the largest visible

action but are forbidden as ``seed_frame_id``.
