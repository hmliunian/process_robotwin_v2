01 · Project scope

项目目标与数据范围

从真实机器人操作视频中识别被操作物与放置区域，生成可追溯的 visible-only mask、完整 overlay 视频及人工复核证据。

OBJECTIVE

标注对象角色

识别被抓取移动的 target，以及动作完成时与之接触的 receiver。

INPUT

真实 Episode 数据

读取 cam_high RGB 视频、state/action 时序及任务文本，通过状态事件建立合法 seed 与角色输出窗口。

OUTPUT

可审计标注产物

loop.json、semantic_plan.json、mask_qc.json、四通道 masks.npz、overlay 与 review sheets。

RUNTIME

本次技术配置

Qwen 负责语义与视觉 QC，SAM3 负责候选分割和视频传播；遮挡区域不做 amodal 补全。

03 · Open-set resolution

S1–S3 开放集 Mask 解析

这里的 S1/S2/S3 是失败救回能力标签，不是上面三个 Pipeline Stage。S2 从语义规划起始即生效；运行时顺序仍是 text attempts → 最后的 bbox attempts。

S1 · TEXT-FIRST

多 Query · 多合法 Seed

按 query bank 顺序生成候选，追加受配置约束的 curated aliases；语义 seed 未通过时，再尝试 State Loop 声明的其他合法 seed。

—角色通过额外合法 seed 救回
S2 · OPEN-SET POLICY

外观语义 · 严格身份 QC

允许用颜色、形状和真实外观描述非典型资产，并结合完整部件、同步运动与夹爪接触证据检查候选身份。

—episode 使用 open-set semantic/QC
S3 · BBOX FALLBACK

Qwen BBox → SAM Box Mask

只有全部 text query × legal seed 都 rejected/ambiguous 后才进入。原始 bbox 不 clamp、不扩框，最终 mask 仍须通过同一套 QC。

—进入 S3 / 通过 S3 的角色
Semantic query bank→Curated aliases×Legal seeds→Mechanical gate + visual QC→ rejected only →Qwen bbox→SAM box mask + same QC
安全边界：第一个 passed 候选立即停止；任何服务、parser、prompt 或候选 shape 的 error 立即停止当前角色，不静默进入下一 fallback。不按面积选最大候选，不合并候选。
历史实验参考（与本次 run 统计分开）

历史 52 条已知失败切片中：S1 新救回 23 条，S2 再救回 17 条，S3 再救回 4 条，累计 44/52（84.62%）。这是独立失败切片实验，不是本次 30 条输入的成功率，也不是严格单变量消融。

09 · Lineage & reproducibility

产物血缘与复现方式

所有汇报统计来自 process summary、render manifest 和逐 episode 产物；HTML 不内嵌视频 Base64，移动时应保留整个 rendered_videos 目录。

产物链路

RoboTwin episode
  ├─ loop.json
  ├─ semantic_plan.json
  ├─ mask_qc.json
  ├─ run_manifest.json
  └─ masks.npz
        ↓ renderer
rendered_videos/
  ├─ manifest.json
  ├─ *.mp4
  ├─ review_sheets/*.jpg
  └─ report.html

本地打开

进入 rendered_videos 目录后启动静态 HTTP 服务：

python3 -m http.server 8000 --directory .

# 浏览器打开
http://localhost:8000/report.html

也可直接双击 report.html；HTTP 模式对不同浏览器的视频 seek 和大图加载更稳定。

当前结果边界

  • 本次为 object-source-only：gripper producer 未运行，红色通道不代表已验证结果。
  • visible-only mask 不补全遮挡区域；黄色 hold encoding 只保留“抓持中”语义。
  • S1/S2/S3 同时启用，本次 run 不是单独 ablation，不能把单条成功完全归因于一个能力。
  • Renderer 只展示 canonical mask；空白 overlay 可能是上游 reject/quarantine 的预期结果。
