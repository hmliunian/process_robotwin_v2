角色定义：
- target：随后被夹爪抓取并移动的完整物体。

本模式只识别 target，不推断也不输出其他放置对象。请跟随 active_arm 对应的夹爪，利用
任务文本和多帧动作关系确认真正被抓取并持续持有的实例，不要只凭一张静态图猜测。
close_end 之后的图像只用于确认对象身份，不会延长 target 的 mask 时间窗口。

对 target：
1. 只能从 target 允许的 seed 候选中选择一个完整、清晰、遮挡最少的 seed frame。必须逐一
   比较所有允许候选，不得因为 frame id 最小或排在输入最前就默认选择。若多个候选接近，
   优先选择跨相邻候选外观稳定、曝光正常且夹爪尚未接触主体的帧，并在 reason 中写明比较依据；
2. 输出有序 query candidate bank，而不是一条长 referring expression；
3. 每条非空 query 必须是 1–4 个小写英文词组成的、指向完整物体的单数名词短语；
4. query 必须保留完整类别名。颜色词或形状词不能充当 head noun，例如 bottle 不能只写
   white。每条 query 总词数不得超过 4；
5. 只使用多帧中稳定可见的属性，不猜测无法确认的属性；
6. 禁止冠词/所有格、品牌或 OCR 文字、数字、动作、位置、空间关系、比较级以及包含
   with 的长属性串；禁止只描述 cap、logo、label、handle 等子部件；
7. category_query 必须是简单、常见、可直接检测的无修饰完整类别，通常使用物体 head noun；
   不得把任务文本中的用途、商品亚型或尺寸词拼成类别。general_fallback_query 必须更一般但
   仍是有视觉意义的完整物体类别；如果没有合理上位类别就填写 null，禁止使用 object、thing、
   item、stuff 等空泛词；
8. recommended_order 排的是预计 SAM3 分割鲁棒性，不是描述详细程度。如果提交帧中没有第二个
   同类别实例，recommended_order 第一项必须是 category_query；只有确实看见多个同类别实例、
   需要属性消歧时，颜色或形状候选才可排第一；
9. 所有非空候选必须互不相同。若某个可选字段只能生成与已有候选相同的短语，或没有独立的
   真实视觉依据，必须将该字段写为 null。recommended_order 只列所有非空候选字段且不重复；
10. 如果没有任何允许候选清楚显示完整 target，返回 no_clear_seed，不得选择局部或其他实例。
